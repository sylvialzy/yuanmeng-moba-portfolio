AI PROJECT CASE STUDY / HUMAN–AI COLLABORATION

人机协作完成游戏策划作品集网页

把分散的实习材料，整理成一份可展示、可播放、可在线访问的作品集
项目一句话：我提供真实材料、做内容判断和最终验收；AI通过一问一答收集信息，整合内容，生成网页初版，再根据我的反馈持续修改，最终完成了一个可编辑并可在线访问的游戏策划作品集网页。
AI协作项目游戏策划作品集HTML / CSS网页部署
01 / WHY

为什么做这个项目

我在准备游戏策划求职作品集时，遇到了四个问题：实习期间做过很多卡牌，但材料分散在Excel、方案表和视频中；不同卡牌缺少统一的展示方式；个人能力很难从大量作品中提炼出来；同时我不会制作网页，无法把实机视频和文字内容整合到一起。

因此，我希望借助AI把已有材料整理成一套系统化作品集：既能说明我做了什么，也能解释为什么这样设计、如何落地和如何验证；同时把视频放进网页，让访问者可以直接查看。

02 / INTERACTION

我如何和AI交互

我们没有一开始就让AI直接生成整份作品集，而是采用“先收集信息，再整合成稿，最后由我反馈修改”的一问一答方式。

我提供简历、卡牌Excel、项目背景、实机视频和自己记得的设计细节。
AI提问一次只确认一个主题，例如个人职责、设计动机、机制闭环、平衡限制、测试方式和上线状态。
我确认判断AI整理的内容是否符合事实，补充遗漏信息，修正卡牌名称和职责边界。
AI整合把确认后的信息整理成项目案例、流派分类、个人能力和网页结构，生成第一版页面。
我反馈通过截图指出具体修改，例如删除某段、增加复活卡、合并单元格、调整标题间距和删掉提示文字。

我保留的判断

  • 哪些经历是真实且值得展示的
  • 哪些卡牌是独立设计、参与制作或设计储备
  • 项目是否已落地、测试或上线
  • 页面内容是否适合招聘场景

AI承担的工作

  • 把问题拆小并逐步追问
  • 整理和改写已确认的信息
  • 生成网页结构和样式
  • 处理视频、路径和部署问题
03 / ITERATIONS

几次关键迭代，以及为什么迭代

信息收集解决“有材料但讲不清”
初版整合解决“作品太多难归类”
页面精修解决“信息密度和排版”
发布交付解决“视频无法跨设备播放”
从经历到案例为了让每张代表卡牌不只是效果罗列，补充设计目标、机制、平衡和验证。
从单卡到体系为了展示系统性，把冰夷、诺娃和公共卡按流派与玩法类别重新组织。
从文字到网页为了让访问者更直观看到实机效果，加入视频组件并优化页面层级。
从本地到在线为了让别人直接打开，修正本机路径，压缩23个视频并部署为单链接网页。

05 / LEARNING

我在这次项目中得到什么

学会把复杂信息结构化

不再只是罗列“我做过哪些卡牌”，而是用问题、目标、机制、平衡、验证和结果讲清作品。

理解人机协作的边界

AI可以帮助发散、整理和执行，但事实确认、设计取舍和最终质量必须由人负责。

建立了网页制作能力

从不会制作网页，到可以看懂并修改HTML/CSS，处理图片、视频、相对路径和页面排版。

形成了迭代解决问题的方法

遇到播放失败、排版问题或上传超限时，能够定位原因、比较方案并完成交付。

可复用的方法：明确目标 → 提供真实材料 → 一问一答收集信息 → 人工确认事实 → AI生成初版 → 截图反馈 → 局部迭代 → 验证交付。
